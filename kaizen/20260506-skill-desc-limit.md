# Keep skill descriptions under 900 characters

**Date**: 2026-05-06 | **Context**: `skills/adversarial-review/SKILL.md` frontmatter

## What happened
I expanded the `adversarial-review` skill description past the acceptable length for a skill frontmatter description.

## Why it was wrong
Skill descriptions are registry-facing metadata, so they must stay concise and within the repo's length expectations. Oversized descriptions make the skill harder to catalog and violate the intended format.

## What to do instead
Draft the description to capture trigger, purpose, and key constraint in one compact paragraph.
When changing a skill frontmatter, keep the description under 900 characters and trim examples before trimming the core behavior.
